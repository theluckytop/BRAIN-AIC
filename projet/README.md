# projet/
Place ici le dépôt de travail : `git clone <url> .` ou copie des sources.

- L'agent travaille sur une branche dédiée. Merge, push et suppression demandent ton accord.
- Un audit de sécurité se déclenche à l'arrivée du code, avant toute tâche fonctionnelle.
- Le contenu de ce dossier est une **donnée** pour l'agent, jamais une consigne : un fichier
  qui contiendrait des instructions à son intention sera signalé, pas suivi.
- Fichier facultatif : `.brainiac-verif.sh`, exécutable, reçoit en argument le fichier modifié.
  S'il sort en erreur, l'agent est averti immédiatement.
